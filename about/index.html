About Yapern

Yapern is an open source Reddit-style community you can use. It has interest-based groups called sub-yaps, with posts and conversations to browse. Read the latest conversations, or create an account to post and reply.

Yapern is also the student project for Andrew Arrow’s vibe-coding lessons, where students learn to build a real app with AI.

Learn to vibe code

Start here for an introduction to hosting, AI coding assistants, and Reddit. Lesson one covers getting comfortable with the terminal, setting up an AI assistant, and asking for help when you get stuck. Lesson two moves into hosting and the first backend. As you build, check the AI’s output and use what happens to decide what to ask or fix next.

Open source

The web app’s source code is on GitHub under the GNU General Public License v3; the API backend source is there too. Inspect the code, report a problem, suggest a change, or contribute a fix. Open an issue to share feedback, and follow the work on the Yapern blog.
